# Python Banking System

## Introduction
The Python Banking System is a beginner-friendly project developed as part of Internship Week 3.

The project uses Object-Oriented Programming (OOP) concepts to create a simple banking application.

## Objectives
- Understand classes and objects.
- Learn constructors and methods.
- Implement encapsulation.
- Understand inheritance and polymorphism.
- Learn abstraction.
- Build a banking application using Python.

## Technologies Used
- Python 3
- Object-Oriented Programming
- VS Code / PyCharm
- GitHub

## Features
1. Create a new bank account.
2. Create Savings and Current accounts.
3. Deposit money.
4. Withdraw money.
5. Check account details and balance.
6. View transaction history.
7. Handle invalid inputs and errors.

## OOP Concepts Used

### 1. Classes and Objects
Classes define the structure of objects. Objects represent individual bank accounts.

### 2. Encapsulation
Account balance and account number are stored as protected attributes to control access to account information.

### 3. Inheritance
SavingsAccount and CurrentAccount inherit properties and methods from BankAccount.

### 4. Polymorphism
Both account types implement their own withdrawal method.

### 5. Abstraction
The BankAccount abstract class defines the common structure and requires subclasses to implement withdrawal functionality.
